The files in this directory contain information about the various "design" decisions about the project
- `code-design.md` - the way the code is laid out in the directory, what code can do what, how the state flows, etc
- `game-design.md` - information about the design of the game itself - what the different features are, how they interact, etc
- `decisions.md` - a dated log of design/architecture decisions: what was decided, when, and why
- `how-the-game-works.md` - plain-language explanation of how the game works, for people reading the source (the
  in-game How to Play screen is written separately, for players)
- `todo.md` - known work that still needs doing: fixes, cleanup, follow-ups, and planned features
